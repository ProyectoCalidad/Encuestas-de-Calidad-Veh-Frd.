    Cómo hacer la entrega cada mes

    1. Abrí esta página desde el link publicado (no con doble clic), así puede armar el HTML.
    2. Cargá la BBDD (hoja acumulada, con todos los meses).
    3. Descargá los tres archivos.
    4. Subí solo el data.json a GitHub (Add file → Upload files, y confirmá que reemplaza al existente).
    5. El HTML y el Excel salen por mail o por el medio que uses con el cliente.
